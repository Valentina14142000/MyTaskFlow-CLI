##  Overview

**MyTaskFlow-CLI** is a high-performance productivity suite designed for developers and power users. It combines a robust command-line interface for rapid task execution with a sleek, Polypost-inspired web dashboard for visual task scheduling, raw task dumping, and automated AI prioritization.

##  Key Features

* **Raw Task Dump**: Instantly brain-dump unstructured thoughts and let automated scheduling organize your day.
* **Hybrid Architecture**: Decoupled static frontend hosted on GitHub Pages paired with a secure serverless backend.
* **Adaptive Themes**: Seamless toggle between clean light mode and immersive dark mode.
* **Audio & Speech Feedback**: Integrated Web Audio chimes and voice feedback for task completion cues.
* **Terminal Power**: Full CLI script execution for offline or terminal-first workflows.

## Getting Started

1. Clone the Repository
```Bash
git clone [https://github.com/Valentina14142000/MyTaskFlow-CLI.git](https://github.com/Valentina14142000/MyTaskFlow-CLI.git)
cd MyTaskFlow-CLI
```

2. Run the Terminal CLI
```Bash
python main.py
```
