# MyTaskFlow-CLI

An elite, terminal-based AI productivity assistant.

## Getting started

```bash
git clone https://github.com/Valentina14142000/MyTaskFlow-CLI.git
cd MyTaskFlow-CLI
python main.py
```

## Project structure

- `main.py` - CLI entry point
- `server.js` - server component
- `src/` - source code
- `index.html` - GitHub Pages landing page
